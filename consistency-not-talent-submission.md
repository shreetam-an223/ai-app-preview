# Assignment 3: Consistency, Not Talent (and Frame, Not Upstage)

## 1. Visual Identity & Design Tokens

### Color Hierarchy (60-30-10 Rule)
- **Dominant Base (60%):** `#020617` — Low-luminance dark slate foundation.
- **Surface / Containers (30%):** `#0F172A` — Distinct card and navigation container background.
- **Accent Highlight (10%):** `#38BDF8` — Sky blue reserved strictly for interactive CTAs, active links, and focus rings.
- **Structural Borders:** `#1E293B` — Subtle 1px solid container borders providing clean boundary separation.

### Typography System
- **UI & Prose Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
  - Headers: `24px` / Bold
  - Body: `15px` / Line-height `1.5` / Regular
- **Technical & Code Stack:** `ui-monospace, "Fira Code", monospace`
  - Code Snippets, Variables, and Diagnostic Logs: `13px` / Regular

### Framing Constraints ("Frame, Not Upstage")
- Applied standard 8px grid spacing (`8px`, `16px`, `24px`, `32px`).
- Eliminated all decorative drop-shadows, rainbow gradients, and background particle animations.
- Ensured container borders frame technical content neutrally, placing focus entirely on functional artifacts.

## 2. AI Asset Evaluation & Rejection Log

| Criteria | Option A: AI-Generated Concept Graphic | Option B: Authentic Production UI Screenshot |
| :--- | :--- | :--- |
| **Asset Type** | Abstract 3D futuristic code visualization | High-resolution capture of live Next.js / React app |
| **Visual Elements** | Glowing cybernetic wires, neon floating shapes | Form inputs, dynamic variable interpolation, server health log |
| **Editorial Verdict** | **REJECTED** | **SELECTED** |
| **Signal-to-Noise Ratio** | Low — purely decorative; provides zero proof of competence | High — proves running code, routing, and proper layout |
| **Impact on Work** | Upstages and distracts from actual engineering artifacts | Frames the software clearly and provides direct verification |

---

## 3. Core Takeaways on Working with AI
- **Restraint Over Generation:** AI can generate hundreds of high-gloss assets effortlessly, but professional credibility comes from deliberate curation and knowing what to reject.
- **Proof Beats Polish:** Authentic UI states, test runs, and clear technical typography provide genuine proof of capability far better than decorative AI illustrations.
