# Portfolio Identity Kit

---

## 1. Typography
* **Heading & Title Font:** `Inter` (Sans-serif, Weight: 600 / Semi-Bold)
* **Body & UI Font:** `Inter` (Sans-serif, Weight: 400 / Regular)
* **Code & Terminal Font:** `JetBrains Mono` (Monospace, Weight: 400 / Regular)

---

## 2. Color Palette (Hex Codes)

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Background** | Near-White Canvas | `#F8FAFC` (Slate 50) | Main page background |
| **Surface / Card** | Clean White | `#FFFFFF` | Project cards, containers, dialogs |
| **Primary Text** | Near-Black Ink | `#0F172A` (Slate 900) | Body copy, headers, primary labels |
| **Muted Text** | Neutral Charcoal | `#64748B` (Slate 500) | Metadata, subheadings, timestamps |
| **Single Accent** | Calm Electric Indigo | `#4F46E5` (Indigo 600) | Primary buttons, active links, focus states |
| **Subtle Border** | Hairline Slate | `#E2E8F0` (Slate 200) | 1px clean container framing |

---

## 3. Logo & Favicon Specification
* **Brand Mark / Wordmark:** Minimalist typographic monogram `[ PS ]` (Prompt Studio) set in `Inter Semi-Bold` inside a `24x24px` rounded container (`#0F172A` background with `#F8FAFC` text).
* **Favicon Design:** SVG square icon (`16x16px` / `32x32px`) featuring a subtle indigo dot (`#4F46E5`) adjacent to clean geometric letterforms `P·S`.

---

## 4. Two-Line Style Note (For AI Project Instructions)
> **Style Note:**  
> Palette uses `#F8FAFC` canvas, `#0F172A` high-contrast ink, `#E2E8F0` hairline borders, and a single `#4F46E5` indigo accent; typography relies exclusively on `Inter` and `JetBrains Mono`.  
> Mood is calm, editorial, and unobtrusive—designed like an art gallery frame where working code and authentic UI proof remain the loudest elements on the page.
