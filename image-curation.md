## 2. Where Authentic Captures Beat AI Stand-ins

* **Software UI & Architecture:**  
  * *Decision:* Used 100% real browser screenshots of `PromptStudio` and runtime diagnostic endpoints instead of AI-generated dashboard mockups.
  * *Rationale:* AI dashboards generate plausible-looking but non-functional fake widgets and garbled text. A real cropped screenshot with actual monospace code provides indisputable proof of working code.
* **Personal Representation:**  
  * *Decision:* Used an authentic photograph for the author profile rather than an AI avatar or stylized digital portrait.
  * *Rationale:* AI-generated avatars signal anonymity or template portfolios; an authentic photo establishes credibility and accountability.

## 3. Rejection Log & Editorial Judgment (Ruthless Curation)

### Rejected Item 1: Abstract AI "Neural Network Code Brain"
* **Asset Type:** AI-generated 3D glowing holographic neural network with floating binary digits and neon purple light rays.
* **Why Rejected:** Upstages the actual engineering. It is visually noisy, clashes with the calm `#020617` / `#38BDF8` design tokens, and acts as decorative filler that gives zero insight into actual software capability.

### Rejected Item 2: AI-Generated "SaaS Analytics Dashboard" Mockup
* **Asset Type:** AI-generated glassmorphic control panel with fictitious charts and glossy 3D metric cards.
* **Why Rejected:** It fakes functionality. Replacing real project outputs with glossy AI concepts destroys trust during technical review. Real, unembellished UI screenshots win every time.

## 4. Cohesion Rule Check
* **Consistent Palette:** All connective assets and captures adhere strictly to dark slate (`#020617`), neutral borders (`#1E293B`), and electric sky/indigo accents.
* **Framing Principle:** 100% of images serve either as concrete proof of work or as invisible framing. Zero decorative clutter.
